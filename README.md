# Eventora — Event Management Website

Eventora is a modern, responsive event management website built using HTML5, CSS3, and JavaScript.

It allows users to explore upcoming events, search and filter events by category, view event details, and register for their preferred events.

## Features

* Responsive website design.
* Modern dark and light themes.
* Dynamic event cards.
* Event search functionality.
* Category-based filtering.
* Detailed event information.
* Event countdown display.
* Registration form with JavaScript validation.
* Registration confirmation messages.
* My Registrations dashboard.
* Local Storage-based registration management.
* Cancel registration functionality.
* Responsive mobile navigation.

## How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_LINK
   ```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server.

4. Explore events and test the registration functionality.

## Registration Management

Eventora uses browser Local Storage to save registration information.

Users can view and cancel their saved registrations through the My Registrations dashboard.

Note: Registration information is stored locally in the user's browser. The current version does not use a backend database or provide centralized multi-user registration management.
